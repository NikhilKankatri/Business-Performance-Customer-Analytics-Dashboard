# Business Performance & Customer Analytics Dashboard

An interactive Power BI dashboard designed to analyze business performance, customer behavior, sales performance, profitability, and key business metrics.

## Project Overview

This dashboard transforms business and customer data into interactive visual insights to support data-driven decision-making.

- Business performance analysis

- Sales performance
- Profitability analysis
- Customer segmentation
- Regional performance
- Product/category analysis
- Trend analysis
- KPI monitoring

## Dashboard Features

- Interactive filters and slicers
- KPI cards
- Interactive charts
- Customer analysis
- Business performance analysis
- Sales and profit analysis
- Trend visualization
- Category and regional analysis
